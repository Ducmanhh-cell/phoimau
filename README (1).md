# Bài Tập: Phối Màu Cho Newsletter

Dự án thực hành sử dụng **Adobe Color** để lựa chọn bộ màu sắc và áp dụng vào giao diện Newsletter xây dựng bằng **Bootstrap 5** và **CSS Variables**.

## 📌 Các phiên bản Newsletter

Dự án bao gồm 2 phiên bản giao diện với 2 phong cách màu sắc hoàn toàn khác nhau:

### 1. Phiên bản 1: Năng động & Trẻ trung (Trello Style)
- **Tệp nguồn:** `newsletter_v1.html`
- **Quy tắc phối màu:** Triad (Bộ ba)
- **Bảng màu HEX:**
  - `--primary-color`: `#0079BF` (Xanh lam Trello)
  - `--secondary-color`: `#FF9F1A` (Vàng cam nổi bật)
  - `--accent-color`: `#EB5A46` (Đỏ san hô)
- **Cảm nhận:** Tươi mới, hiện đại, kích thích sự chú ý và tương tác của người dùng.

---

### 2. Phiên bản 2: Thanh lịch & Chuyên nghiệp (Corporate Style)
- **Tệp nguồn:** `newsletter_v2.html`
- **Quy tắc phối màu:** Analogous (Tương đồng)
- **Bảng màu HEX:**
  - `--primary-color`: `#264653` (Xanh ngọc sẫm - Deep Teal)
  - `--secondary-color`: `#E76F51` (Cam đất - Terracotta)
  - `--accent-color`: `#2A9D8F` (Xanh Mint sẫm)
- **Cảm nhận:** Trầm ấm, uy tín, thích hợp cho các bản tin báo cáo phân tích doanh nghiệp.

---

## 🚀 Hướng dẫn khởi chạy

1. Tải về hoặc clone repository này về máy:
   ```bash
   git clone <URL_REPOSITORY_CỦA_BẠN>
   ```
2. Mở file `index.html` trực tiếp trên trình duyệt để lựa chọn và xem cả 2 phiên bản.
